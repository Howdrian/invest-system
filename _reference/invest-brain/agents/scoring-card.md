# 交易决策评分卡 (Trading Decision Scoring Card)

> 每次交易决策的量化评分工具
> 与 red-team-protocol.md 配合使用，在仲裁阶段执行

---

## 评分维度（总分 0-10）

### 1. 基本面强度 (0-2分)

**商品标的**：
| 得分 | 标准 |
|------|------|
| 0 | 供需平衡或供过于求，无结构性缺口 |
| 0.5 | 有缺口但被库存覆盖 |
| 1.0 | 结构性供应缺口，库存在下降 |
| 1.5 | 缺口扩大，替代供应需要3年+才能上线 |
| 2.0 | 严重供应危机，短期内无法缓解 |

**个股标的**：
| 得分 | 标准 |
|------|------|
| 0 | 财务恶化，亏损扩大，负自由现金流 |
| 0.5 | 盈利但增速放缓或低于行业 |
| 1.0 | 稳定盈利，合理估值（P/E在行业均值附近） |
| 1.5 | 高增长+盈利改善，估值低于增速（PEG<1） |
| 2.0 | 爆发性增长+强现金流+护城河+估值合理 |

### 2. 催化剂明确性 (0-2分)

| 得分 | 标准 |
|------|------|
| 0 | 没有可识别的催化剂，纯粹基于"总会涨" |
| 0.5 | 有模糊的催化剂但时间不确定（"某天会..."）|
| 1.0 | 有明确催化剂但时间窗口较宽（3-6个月内）|
| 1.5 | 催化剂明确且时间窗口较窄（1-3个月内） |
| 2.0 | 多个催化剂即将在确定日期触发（财报日、政策日期等）|

### 3. 风险回报比 (0-2分)

| 得分 | 标准 |
|------|------|
| 0 | 止盈/止损比 < 1:1（可能亏的比赚的多）|
| 0.5 | 止盈/止损比 1:1 到 1.5:1 |
| 1.0 | 止盈/止损比 1.5:1 到 2:1 |
| 1.5 | 止盈/止损比 2:1 到 3:1 |
| 2.0 | 止盈/止损比 > 3:1（不对称回报机会）|

**计算方法**：
```
止盈空间 = 目标价 - 当前价
止损空间 = 当前价 - 止损价
风险回报比 = 止盈空间 / 止损空间
```

### 4. 时机判断 (0-2分)

| 得分 | 标准 |
|------|------|
| 0 | 追高买入（已连续上涨20%+），或接飞刀（下跌趋势未企稳） |
| 0.5 | 价格在高位盘整，方向不明 |
| 1.0 | 价格在合理区间，无明显追高或抄底 |
| 1.5 | 从关键支撑位反弹 / 突破关键阻力位+回踩确认 |
| 2.0 | 恐慌抛售后的超跌反弹 / VIX极端值后的反转 |

### 5. 红队反面论证强度 (0-2分)

**注意：这项是反向评分——红队攻击越强，得分越低**

| 得分 | 标准 |
|------|------|
| 0 | 红队找到了致命且无法反驳的风险（如财务造假证据、监管确认调查）|
| 0.5 | 红队找到了2-3个严重风险，蓝队只能部分反驳 |
| 1.0 | 红队找到了风险但蓝队有合理反驳，双方势均力敌 |
| 1.5 | 红队的攻击大部分被蓝队有效反驳，剩余风险可管理 |
| 2.0 | 红队未能找到实质性致命风险（罕见，需警惕是否红队没认真攻击）|

## 个股加权综合评分（补充维度）

当分析对象为**个股**时，除基础5维度评分外，额外输出加权综合评分（来自 Research Bundle 模型）：

| 维度 | 权重 | 来源 |
|------|------|------|
| 业务质量 | 25% | Piotroski F-Score + 护城河评分 |
| 估值 | 25% | DCF安全边际 + 可比公司对比 |
| 市场信号 | 20% | 内部人交易 + 机构持仓变化 |
| 技术面 | 15% | 趋势 + 支撑阻力 + 动量 |
| 风险 | 15% | 红旗数量 + 下行空间量化 |

综合评分 = Σ(维度分 × 权重)，0-10范围。

详见 `frameworks/equity-analysis.md` 第七节。

## 使用注意事项

1. **不要追求满分**：8分以上的机会非常稀少。如果频繁出现8+评分，说明评分标准太松
2. **6分是正常的好机会**：大部分值得做的交易在6-7.5分之间
3. **关注关键假设**：评分是静态的，但市场是动态的。当关键假设被打破时，必须重新评分
4. **记录每次评分**：事后回顾评分准确性，持续校准标准
5. **卖出也要评分**：不只是买入。"我该不该卖CCJ"也要走红蓝对抗+评分
6. **做空标的评分**：5个维度的解读方向反转（基本面越弱分越高、红队找做多理由），详见 `frameworks/short-selling.md` 第六节
