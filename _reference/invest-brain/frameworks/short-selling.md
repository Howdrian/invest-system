# 做空分析框架

> 方法论来源：Jim Chanos (Kynikos Associates) SEC证词、Asquith et al. (2005, JFE)、Desai et al. (2002, JF)、AQR长短研究
> 适配 invest-brain 的红蓝对抗流程
> 覆盖：卖空股票 + 买入Put期权

---

## 使用方式

invest-brain 在检测到做空/买put意图时自动加载本框架。
分析完成后进入红蓝对抗（`agents/red-team-protocol.md`）+ 评分（`agents/scoring-card.md`）。
**做空交易必须强制红蓝对抗。**

## 二、红旗识别框架

> 来源：Chanos SEC证词 + Congressional Testimony

### 会计异常（最重要）

| 红旗 | 严重程度 | 检测方法 |
|------|---------|---------|
| 报告盈利与现金流背离 | 🔴 致命 | 对比净利润 vs 经营现金流，差距>30%需警惕 |
| 频繁变更会计方法/重述 | 🔴 致命 | 查SEC filing历史，2年内重述>1次 |
| 依赖一次性收益达标 | 🟡 严重 | 剥离非经常性损益后看实际盈利 |
| 激进使用gain-on-sale | 🟡 严重 | Enron即用此手法虚增利润 |
| ROIC < WACC | 🟡 严重 | 每投入1元产出<1元，在摧毁价值 |

### 管理层行为

| 红旗 | 严重程度 | 检测方法 |
|------|---------|---------|
| CFO/Controller离职 | 🔴 致命 | 财务高管离职+公司不解释原因 |
| 内部人减持+公开唱多 | 🔴 致命 | 言行不一是最强信号 |
| 面对质疑过度防御 | 🟡 严重 | 电话会/采访中回避具体问题 |
| 关联方交易 | 🟡 严重 | 表外工具、隐藏负债 |

### 量化信号

| 信号 | 数据 | 来源 |
|------|------|------|
| Short interest ratio ≥ 2.5% | 后续12个月显著负异常收益 | Desai et al. (2002, Journal of Finance) |
| 高short interest + 低机构持股 | 月均超额负收益 -215bps (等权重) | Asquith et al. (2005, JFE, MIT) |
| 满足条件的标的稀缺 | 月均约21只 | Asquith et al. |

```
做空信号强度排序：
1. 会计红旗 + 内部人减持 = 最强信号
2. 高short interest + 低机构持股 = 量化确认
3. ROIC < WACC 持续3年+ = 结构性做空
4. 单纯技术面超买 = 最弱信号，不应单独使用
```

## 三、技术面做空信号

> 来源：QuantifiedStrategies回测数据

### 信号有效性排序

| 信号 | 回测胜率 | 标的/期间 | 可靠性 | 说明 |
|------|---------|----------|--------|------|
| MACD死叉 + RSI≥75 | **73%** | SMH, 2001至今, 235笔 | 中 | 单一标的回测，可能过拟合 |
| RSI>70 单独使用 | 不可靠 | — | 低 | 强趋势中可长期>70，做空会被碾压 |
| Death Cross (50/200) | 做空年化仅 **0.4%** | S&P 500 | 极低 | 死叉后1年2/3时间指数上涨 |
| 单独MACD交叉 | ~**40%** | — | 极低 | 比抛硬币还差 |

### 实操规则

```
技术面做空仅作为辅助确认，不作为独立做空依据：
1. 基本面做空逻辑先行（红旗识别）
2. MACD死叉 + RSI≥75 作为入场时机确认
3. 永远不要仅凭技术指标做空
4. Death Cross → 仅用于防御性减仓，不用于主动做空
```

## 四、工具选择：卖空 vs 买Put

> 来源：Interactive Brokers、Benzinga、Tickeron

以100股 × $150 = $15,000头寸为例：

| 维度 | 卖空股票 | 买入Put |
|------|---------|---------|
| **最大亏损** | **无限**（股价可无限涨） | **有限** = 权利金（如$1,000） |
| **初始保证金** | 50% = $7,500 | $0（仅付权利金） |
| **维持保证金** | 持续调整，上涨则追加 | 无 |
| **借券成本** | 持续支付 | 无 |
| **时间衰减** | 无 | 每日损耗（theta） |
| **资本效率** | 低（占大量保证金） | **高**（小资金控制大头寸） |
| **到期限制** | 无到期日 | **有到期日** |

### 选择判断框架

```
高确信度 + 短期催化剂明确 → 卖空（无时间衰减）
确信度中等 + 尾部风险担忧 → 买Put（锁定最大亏损）
难借/借券费率高 → 买Put
长期论据需时间验证 → 卖空（无到期压力）
资金有限 → 买Put（资本效率高）
不确定时的默认选择 → 买Put（风险有底）
```

## 五、做空仓位管理与风控

> 来源：Chanos方法论、Resonanz Capital框架

### 仓位规则

| 规则 | 参数 |
|------|------|
| 单笔做空风险 | 账户资本的 **1-2%** |
| 单个做空仓位范围 | **0.5% - 5%**（Chanos标准） |
| 建仓方式 | 小仓位起步，证据积累后加码 |
| 做空总敞口上限 | 建议不超过账户的 **30%** |

### 止损计算

```
做空仓位大小 = 账户风险金额 / 止损距离

示例：
- 账户 $100,000，每笔风险 1% = $1,000
- 做空入场 $50，止损 $55（距离 $5）
- 仓位 = $1,000 / $5 = 200股
- 头寸价值 = 200 × $50 = $10,000 = 账户10%

做空止损距离 = 止损价 - 入场价（方向相反）
```

### 做空特有风险应对

| 风险 | 应对 |
|------|------|
| 无限亏损 | 严格止损 + 仓位上限5% |
| 逼空 (Short Squeeze) | 监控short interest ratio，避免过度拥挤标的 |
| 借券召回 | 分散券源，优先做空大市值流通股 |
| 保证金追缴 | 预留充足缓冲，不满仓做空 |
| 市场长期上涨 | 隔离alpha和beta（用指数对冲系统性风险） |

### 退出规则

```
强制退出：
1. 触及止损价 → 无条件退出
2. 做空论据被证伪（如会计问题被澄清、新管理层上任并改善）→ 退出
3. 仓位膨胀超出目标 → 主动修剪回目标

可选退出：
4. 达到目标价 → 获利了结或收紧止损
5. 持有超过评审期限（如3个月）→ 重新评估是否继续
```

## 六、做空评分适配

做空标的使用 `agents/scoring-card.md` 的标准5维评分，但以下维度调整解读：

| 维度 | 做多时 | 做空时 |
|------|--------|--------|
| 基本面强度 | 越强越好 | **越弱越好**（红旗越多分越高） |
| 催化剂明确性 | 上涨催化剂 | **下跌催化剂**（财报暴雷、监管调查、内部人大量卖出） |
| 风险回报比 | 上涨/下跌 | **下跌/上涨**（做空方向，止盈在下方） |
| 时机判断 | 超跌反弹好 | **超买回落好**（RSI>75+MACD死叉） |
| 红队反面论证 | 红队找做空理由 | **红队找做多理由**（为什么不应该做空） |

**门槛不变：< 6.0 = 不操作。**

## 七、数据管线（2026-03-31 实测验证）

**做空分析依赖以下数据。缺失数据=分析不完整，必须在输出中告知用户。**

| 数据需求 | 数据源 | 状态 | 实测结果 | 延迟 |
|---------|--------|------|---------|------|
| RSI/MACD/BB | technical-analysis skill | ✅ 可用 | 正常返回 | 近实时 |
| 基本面8维评分 | stock-analysis skill | ✅ 可用 | 正常返回 | 近实时 |
| **Short Interest** | stock-analysis skill | ✅ 可用 | AAPL: 0.85% float, 3.17 days to cover | ~2周(FINRA) |
| **内部人交易** | stock-analysis skill | ⚠️ 部分 | 仅返回90天净值($0.0M)，无逐笔明细 | 2-3天 |
| 内部人交易明细 | Yahoo Finance /insider-transactions/ | ✅ 可用 | 逐笔：谁买了/卖了/多少/什么价 | 近实时 |
| **现金流 vs 净利润** | Yahoo Finance /financials/ + /cash-flow/ | ✅ 可用 | AAPL: OCF $135.5B vs NI $117.8B（5年完整） | 季度 |
| **机构持股** | Yahoo Finance /holders/ | ⚠️ 部分 | 有当前快照(65.25%)和Top10，但无增减变化量 | 季度(13F) |
| **期权链+IV** | Yahoo Finance /options/ | ✅ 可用 | 有行权价/价格/OI/IV，但无Greeks和P/C汇总 | 15分钟 |
| 估值指标 | Yahoo Finance /key-statistics/ | ✅ 可用 | P/E/PEG/P/B/EV-EBITDA/ROE/ROA全有 | 近实时 |
| ROIC vs WACC | 无直接数据源 | ❌ 不可用 | 需从财报数据手动计算 | — |
| 会计异常/重述 | 无直接数据源 | ❌ 不可用 | 用Tavily搜索"[TICKER] restatement SEC"替代 | — |
| 借券费率 | 券商API（无） | ❌ 不可用 | 用Tavily搜索"[TICKER] borrow rate short"替代 | — |

### 访问注意

- **stock-analysis skill**：Agent直接调用，稳定可用
- **Yahoo Finance页面**：WebFetch直接请求返回503，**需要Playwright浏览器访问**。如Playwright不可用，降级为Tavily搜索"[TICKER] short interest site:finance.yahoo.com"

### 运行规则

1. 做空分析开始时，先通过stock-analysis skill获取short interest和基本面
2. 深度调研阶段，用Tavily搜索补充：内部人交易明细、现金流质量、借券费率、会计异常
3. 缺失关键数据时，输出必须标注"以下判断因缺少[X]数据而不完整"
4. **不要假装拥有没有的数据**
