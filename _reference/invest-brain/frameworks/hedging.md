# 对冲策略框架

> 方法论来源：Universa Investments (Spitznagel)、CBOE官方指数、SocGen CTA Index、AQR研究、Resonanz Capital
> 适配 invest-brain 的组合保护需求
> 覆盖：尾部对冲、保护性Put、趋势跟踪、Collar

---

## 使用方式

invest-brain 在检测到对冲/保护/组合风险管理意图时自动加载本框架。
对冲决策进入红蓝对抗（`agents/red-team-protocol.md`）+ 评分（`agents/scoring-card.md`）。

## 一、四种对冲策略速览

| 策略 | 年化成本/拖累 | 危机保护力度 | 最佳场景 | 最差场景 |
|------|-------------|------------|---------|---------|
| Deep OTM Put (Universa) | ~6% 股票仓位 | 极端（2020.3月+3,612%） | 黑天鹅崩盘 | 长期横盘（持续失血） |
| 保护性Put (PPUT) | ~3.2% 年化拖累 | 中等（回撤减12%） | 持续下行保护 | 低波动长牛（白交保费） |
| 趋势跟踪CTA | 长期正回报（无净成本） | 中-高（慢熊好） | 2008型持续性熊市 | 急崩+V反（2020.3） |
| Collar (零成本) | ~3% 隐含成本 | 低-中 | 短期锁定大仓位 | 长期持有（放弃上行） |

## 二、Deep OTM Put（Universa模式）

> 来源：Universa投资者信、Bloomberg、Market Sentiment、Spitznagel《Safe Haven》

### 策略参数

- **标的**：S&P 500 指数期权
- **执行价**：约 30% OTM（深度虚值）
- **期限**：2个月到期，每月滚动
- **月度预算**：股票仓位的 **0.5%**
- **年度预算**：约 **6%** 股票仓位

### 推荐配置

```
96.67% S&P 500 + 3.33% Universa式尾部对冲
```

### 实盘/回测数据

| 指标 | 数值 | 来源 |
|------|------|------|
| 2020年3月基金净回报 | **+3,612%** | Bloomberg / Universa投资者信 |
| 2020年YTD基金净回报 | **+4,144%** | Yahoo Finance |
| 组合效果（96.67/3.33）2020.3 | **约+0.4%**（同期SPX -12.4%） | Universa投资者信 |
| 组合自2008至今年化 | **11.5%** | Universa投资者信 |
| 同期S&P 500年化 | **7.9%** | 同上 |
| 高估值时期超额收益 | 年化 **+4%** | Spitznagel《Safe Haven》 |

### 注意事项

- 2008-2019年间Universa基金"仅勉强追平S&P 500"——两次大危机间隔约13年
- 1985-2020完整回测数据未公开（Spitznagel核心商业秘密）
- **高估值时效果最显著**（Tobin Q上四分位）

## 三、保护性Put（CBOE PPUT指数）

> 来源：CBOE官方、Bondarenko (2019)

### 策略构建

- 持有S&P 500全部成分股
- 每月买入 **5% OTM** 的SPX看跌期权（1个月到期）
- 到期后滚动

### 35年实绩（1986.6 — 至今）

| 指标 | PPUT | S&P 500 | 差值 |
|------|------|---------|------|
| 年化复合回报 | **6.64%** | ~9.80% | -3.2% |
| 最大回撤 | **-38.9%** | -50.9% | 好12个百分点 |
| 年化标准差 | **12.08%** | ~15.5% | 低3.5% |
| 月跌>6%次数(35年) | **18次** | 35次 | 减半 |

### 核心结论

- 年化拖累约 **3.0-3.2%**，来源是波动率风险溢价（vol risk premium长期为负）
- 牺牲~3%年化收益，换取回撤从-51%缩到-39%
- 2008/2020危机中回报比SPX高 **10+个百分点**

## 四、趋势跟踪CTA（Crisis Alpha）

> 来源：SocGen SG CTA Index、Graham Capital、RCM Alternatives

### 危机表现

| 事件 | SG CTA Index | S&P 500 | 差值 |
|------|-------------|---------|------|
| **2008 GFC** | **+13%**（部分基金+50%） | -37% | +50个百分点 |
| **2020.3 COVID** | **+0.14%** | -12.4% | +12.5个百分点 |

### 为什么2020年不如2008年

- 23个交易日从历史高点暴跌33%，速度太快
- 趋势跟踪的回望期通常30-90天，23天急跌被视为"噪音"
- 随后V型反弹也未给系统足够时间建仓

### 长期特征

- 年化回报约 **4-6%**
- 与股票的**低相关甚至负相关**是核心价值
- 85%+的回报可由趋势跟踪因子解释
- **无对冲成本**（长期本身正回报）

### 适用规则

```
CTA/趋势跟踪适合：2008型"慢熊"（持续1年+下跌趋势）
CTA/趋势跟踪不适合：2020型"急崩+V反"（23天暴跌+快速反弹）
配置建议：另类配置的 5-15%
```

## 五、Collar策略

> 来源：CBOE CLL指数、AQR (Israelov & Klein)、Fidelity

### 策略构建

- 持有标的
- 买入OTM看跌（通常5% OTM）
- 卖出OTM看涨（通常10% OTM）
- Call权利金抵消Put成本 = "零现金支出"

### CBOE CLL指数表现（1986.7 — 2014.12）

| 指标 | CLL (Collar) | S&P 500 |
|------|-------------|---------|
| 年化回报 | **6.2%** | 9.0% |
| 波动率 | **10.7%** | 15.7% |
| Beta | **0.62** | 1.00 |

### AQR结论

Collar是"相对差的performer"：
1. 只赚取约62%的股票风险溢价（beta 0.62）
2. 波动率偏斜（skew）：买put贵 + 卖call便宜 = 净亏波动率溢价
3. "零成本"只是名义上的——放弃的上行 > 获得的下行保护

### 适用场景

```
适合：短期持有大仓位需要保护（如高管锁定股票、并购等待期）
不适合：长期配置（年化拖累2.8-4.1%，AQR明确反对）
```

## 六、对冲预算指导

> 来源：Resonanz Capital、CAIA、Goldman Sachs、AllianceBernstein

### 基线预算

| 指标 | 数值 | 来源 |
|------|------|------|
| 基线对冲预算 | NAV的 **0.5-1.0%**/年 | Resonanz Capital / 多机构 |
| 尾部对冲基金配置 | 组合的 **2-5%** | Resonanz Capital |
| 尾部对冲年化拖累 | 约 **40 bps** | CAIA |
| 保护15%下跌(12个月)成本 | 约 **3.4%**/年 | 机构期权市场 |
| 保护25%下跌(12个月)成本 | 约 **2.4%**/年 | 同上 |

### VIX体制预算调整

| VIX区间 | 体制 | 建议预算 | 说明 |
|---------|------|---------|------|
| < 15 | 低波动 | **0.5%** NAV | 保险便宜时买入 |
| 15-22 | 正常 | **1.0-1.5%** NAV | 标准保护 |
| 22-30 | 升高 | **2.0-2.5%** NAV | 增强保护 |
| > 30 | 危机 | **不宜新建** | 成本太高，应已有仓位在手 |

### 关键原则

1. **保护前10-15%的回撤即可获得大部分复利保护效果**——不必全额覆盖
2. **在隐含波动率最低十分位时买入凸性**——规则化触发，非主观择时
3. **预先授权变现计划**——危机中将对冲获利再平衡至股票
4. **评估周期至少3-5年**——不因短期carry拖累就取消
5. VIX<15时是买保险的黄金窗口

## 七、对冲策略选择决策树

```
组合需要对冲保护？
│
├─ 担心黑天鹅（极端尾部风险）
│   └─ Deep OTM Put（Universa模式）
│      预算：0.5%/月 × 股票仓位
│      期限：2个月到期，每月滚动
│
├─ 需要持续下行保护
│   └─ 保护性Put（PPUT模式）
│      成本：~3%/年 年化拖累
│      适合：愿意牺牲收益换取平滑回撤
│
├─ 需要低成本长期分散
│   └─ CTA/趋势跟踪配置
│      成本：无净成本（长期正回报）
│      配置：另类配置的5-15%
│      注意：急崩+V反时保护不足
│
└─ 短期需要锁定大仓位
    └─ Collar
       成本：隐含~3%（放弃上行）
       适合：3-6个月短期锁定
       不适合：长期持有
```
