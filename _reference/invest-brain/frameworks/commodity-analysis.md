# 大宗商品分析框架

> 基于 2026年2-3月 美伊战争周期的实战分析总结
> 多轮验证，标注了哪些判断被验证、哪些被打脸

---

## 一、核心公式

### 公式1：恐慌涨金，断供涨油

```
恐慌（不确定性）→ 黄金上涨
断供（实际供应中断）→ 石油上涨
```

这是最基础的判断框架。2026年3月完美验证：
- 战前恐慌阶段：金价冲$5,600（避险情绪）
- 战争爆发+海峡封锁：油价涨35%（实际断供），金价反而跌（买预期卖事实）

**推论**：如果只有恐慌没有断供，油价不会持续涨。如果恐慌已充分定价，开战反而可能是金的卖点。

### 公式2：高价自我治愈

```
价格暴涨 → 需求减少 + 替代出现 + 新供应 → 价格回落
```

每个商品都适用，但时间不同：
- 农产品：1个产季（3-6个月）
- 石油：1-3年（OPEC调产量 + 页岩油增产）
- 金属矿：5-17年（开矿周期）

### 公式3：买预期，卖事实

```
预期阶段（还没发生）→ 价格已经在涨
事实兑现（真的发生了）→ 获利盘涌出 → 可能反而跌
```

验证案例：
- 战前2个月金银已大涨（买预期）
- 2月28日真开战 → 金价冲$5,418后暴跌到$4,980（卖事实）
- 但石油没有这个问题 → 因为石油的"事实"是持续性的断供，不是一次性事件

**区分**：一次性事件（开战、加息决议）适用买预期卖事实。持续性事件（海峡封锁、持续战争）不适用，价格会持续反映。

## 二、反应速度排序

战争/地缘冲突爆发时，商品的反应顺序：

```
第1波（小时级）：黄金 — 纯情绪，资金找安全的地方
第2波（天级）  ：石油 — 供应中断恐慌
第3波（天~周） ：农产品 — 取决于交战国是否主产区
第4波（周~月） ：白银 — 先慢后爆，启动后涨幅超黄金
```

回调顺序（谁先见顶回落）：

```
第1个回调：农产品 — 供应可替代，一个产季重建
第2个回调：石油 — OPEC调产量，需求端效率改善
最后回调：黄金/白银 — 战争→印钱→通胀，链条比战争持久
```

## 三、关键比率监控

### 金银比（Gold/Silver Ratio）

| 区间 | 含义 | 操作信号 |
|------|------|---------|
| >90 | 白银极度便宜 | 买白银 |
| 70-90 | 白银偏便宜 | 可以配置白银 |
| 55-70 | 正常区间 | 按其他因素判断 |
| <55 | 白银偏贵 | 考虑从银换金 |
| <45 | 白银极度贵 | 减持白银 |

近代浮动汇率时代均值：60-65

### 金油比（Gold/Oil Ratio）

| 区间 | 含义 |
|------|------|
| 均值 ~18 | 正常 |
| >40 | 石油相对极度便宜（历史上只出现3次：1986/2016/2020）|
| >70 | 史无前例的极端（2026年3月达到77）|

### 需求毁灭触发线（石油）

| 油价区间 | 效应 |
|---------|------|
| $80-100 | 开始影响消费者行为 |
| $100-110 | 需求毁灭加速（Goldman触发线）|
| $120+ | 持续数月 = 全球衰退风险 |
| $140+ | 历史极端（2008年$147后6个月跌到$32）|

## 四、商品属性分类

### 按驱动力分类

| 类型 | 商品 | 涨的条件 | 跌的条件 |
|------|------|---------|---------|
| 避险型 | 黄金 | 不确定性本身（不管打不打，怕就涨）| 美元走强、流动性紧缩 |
| 断供型 | 石油、天然气 | 实际供应中断（光怕不够，得真断）| 供应恢复、需求毁灭 |
| 经济型 | 铜 | 经济繁荣、工业需求 | 经济衰退（Dr. Copper）|
| 双面型 | 白银 | 避险+工业两个引擎同时燃烧 | 任一引擎熄火就跌得很惨 |

### 按供应弹性分类

| 弹性 | 商品 | 新增供应需要多久 |
|------|------|----------------|
| 高弹性 | 农产品 | 1个产季（3-6个月）|
| 中弹性 | 石油 | 1-3年（页岩油可快一些）|
| 低弹性 | 铜 | 5-17年 |
| 极低弹性 | 铀、白银 | 铀10-15年；白银80%是副产品，无法单独增产 |

**核心规律**：供应弹性越低，牛市持续时间越长，但启动也越慢。

## 五、白银特殊框架

白银不能用简单的金/油逻辑分析，需要单独框架：

### 四重引擎模型

```
引擎1：避险追随（跟黄金）— 金银比从极端回归
引擎2：工业需求（AI+太阳能+EV）— 结构性增长
引擎3：供应刚性（80%副产品+连续赤字）— 无法快速增产
引擎4：投机放大（市场小，资金推动效应2-3倍于黄金）
```

### 白银的风险信号

- 金银比跌到45以下 → 白银偏贵了
- 现货对期货折价 → 实物需求跟不上金融炒作
- ETF资金流出 → 投机退潮
- 太阳能替代加速 → 工业引擎减速（但AI引擎在补上）

### 白银的"先慢后爆"特征

不是"最后涨"，而是：
- 金涨的时候银慢吞吞（因为银还有工业属性在拖后腿）
- 一旦市场确认牛市 → 资金涌入 → 因为盘子小，涨幅远超黄金
- 但反过来跌的时候也是2-3倍于黄金

## 六、天然气特殊框架

### 美国 vs 欧洲是两个完全不同的市场

| | 美国（Henry Hub） | 欧洲（TTF） |
|--|------------------|------------|
| 供应 | 自给自足（页岩气）| 高度依赖进口LNG |
| 受霍尔木兹影响 | 几乎不受 | 直接受影响 |
| 2026年3月战争期间 | 几乎没涨 | 暴涨74% |

### 传导链（慢但确定）

```
卡塔尔LNG停产 → 欧洲/亚洲断供 → 抢购美国LNG → 美国出口增加 → Henry Hub涨
（需要几周到几个月传导）
```

### ETF vs 个股

天然气ETF（UNG/BOIL）有严重展期损耗，长期持有必亏。
→ 投天然气用个股（LNG、EQT、KMI），不用ETF。

## 七、石油的天花板模型

石油不可能无限涨，有三道刹车：

```
刹车1：需求毁灭（$100+消费者减少用油）
刹车2：战略储备释放（SPR + IEA协调）
刹车3：全球衰退（$120+持续数月→经济崩→需求崩→油价崩）
```

历史上每次战争驱动的油价暴涨都以暴跌结束：
- 1979：$39.50 → 1986 $10
- 1990海湾：$41 → 3个月 $20
- 2008：$147 → 6个月 $32
- 2022俄乌：$130 → 年底 $80

**石油投资悖论**：涨得越高 → 离崩盘越近。$100是享受利润的价格，不是加仓的价格。

## 八、超级周期轮涨逻辑

大宗商品超级周期中，不同商品处于不同阶段，不会同涨同跌：

```
2024-2025：第一棒 — 黄金、白银（避险+去美元化）✅ 已大涨
2025-2026：第二棒 — 铜、铂金（工业需求+AI）🔄 正在启动
2026-2027：第三棒 — 天然气、铀（能源安全+核能复兴）⏳ 还在低位
```

**规律**：最好的买入时机是"没人讨论"的时候。当社交媒体都在聊金银时，工业金属和能源可能才是下一个机会。

## 十、分析方法论

### 第一步：确定驱动力类型

问自己：这个商品现在涨/跌，是因为"情绪"还是"供需"？
- 情绪驱动 → 来得快去得快，"买预期卖事实"
- 供需驱动 → 持续性强，但有"高价自我治愈"的天花板

### 第二步：查关键比率

金银比、金油比、库存数据、供应赤字/过剩。
比率处于历史极端 → 大概率会均值回归 → 这是最可靠的信号。

### 第三步：区分"已经涨的"和"还没涨的"

超级周期中轮涨。已经大涨的（金银）→ 追高风险大。
还在低位的（天然气、铀）→ 风险回报比更好。

### 第四步：设定纪律

- 分批建仓（1/3、1/3、1/3）
- 明确买入区间和卖出区间
- 停火/黑天鹅出现时的应急方案
- **最难的不是买对，是知道什么时候走**

### 第五步：持续验证和修正

- 每周检查判断是否仍然成立
- 错了就认，及时修正（我们修正了3次）
- 记录对错，形成反馈循环
