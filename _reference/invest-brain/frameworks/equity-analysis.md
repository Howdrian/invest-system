## 一、财务健康快筛：Piotroski F-Score（0-9分）

9项二元评分（是=1分，否=0分），快速判断"这家公司财务健康吗"：

**盈利能力（4项）**：
1. ROA > 0（正的资产回报率）
2. 经营现金流 > 0
3. ROA 同比增长
4. 经营现金流 > 净利润（盈利质量：现金流比利润更真实）

**杠杆与流动性（3项）**：
5. 长期负债/总资产 同比下降
6. 流动比率 同比改善
7. 未增发新股（不稀释股东）

**运营效率（2项）**：
8. 毛利率 同比提升
9. 资产周转率 同比提升

| F-Score | 含义 | 信号 |
|---------|------|------|
| 8-9 | 财务非常健康 | 强烈看好 |
| 5-7 | 财务一般 | 需要更多分析 |
| 0-4 | 财务堪忧 | **红旗，红队重点攻击** |

## 二、价值创造检验：ROIC vs WACC

```
ROIC > WACC → 公司在创造价值（每投入1元产出>1元）
ROIC ≈ WACC → 平庸，跑个寂寞
ROIC < WACC → 在摧毁价值（每投入1元产出<1元）
```

**关注趋势比绝对值更重要**：ROIC从12%降到8%比从8%到12%更需要警惕。

## 三、估值：DCF + 可比公司交叉验证

### DCF 10年现金流折现

**步骤**：
1. 确定基础指标（TTM自由现金流、收入、利润率、股数、净负债、税率）
2. 预测10年收入（分Bull/Base/Bear三场景，概率20%/60%/20%）
3. 预测FCF利润率（考虑运营杠杆、资本开支、运营资金、股权激励）
4. 计算终值（Gordon增长模型 or 退出倍数法）
5. 计算WACC（CAPM推导权益成本 + 税后债务成本）
6. 折现10年现金流至现值
7. 5×5敏感度矩阵（WACC 6-10% × 终端增长率 1-3%）

**7个必须避免的陷阱**：
1. ❌ 把不可持续的增长率外推10年
2. ❌ 终值占企业价值>80%（说明短期假设太保守或终值太乐观）
3. ❌ WACC低于无风险利率（物理上不可能）
4. ❌ 忽略周期性（用周期顶峰的FCF做基数）
5. ❌ 忽略股权激励稀释（SBC是真实的现金成本）
6. ❌ 只做一个场景（没有Bull/Base/Bear = 自欺欺人）
7. ❌ 忽略运营资金变化（增长吃现金）

### 可比公司法

选3-5个同行业可比公司，对比：
- EV/Revenue、EV/EBITDA、P/E、EV/FCF
- 根据质量/规模差异调整（-25%到+20%）

### 安全边际阈值

| 类型 | 需要的折扣 |
|------|-----------|
| 深度价值投资者 | 低于内在价值 25-35% |
| GARP（合理价格成长） | 低于内在价值 10-20% |
| 成长型投资者 | 可接受0-10%溢价 |

**红蓝对抗用法**：蓝队用DCF论证"便宜"时，红队应该攻击其增长率假设和WACC选择。

## 四、竞争力评估：Porter五力 + 护城河

### Porter五力评分（每项1-5分，换算为0-10总分）

1. **竞争对手威胁**（现有竞争激烈度）
2. **新进入者威胁**（行业壁垒高低）
3. **供应商议价能力**
4. **客户议价能力**
5. **替代品威胁**
6. **行业整体吸引力**（综合以上5项）

### 护城河分类

| 护城河来源 | 诊断标志 | 例子 |
|-----------|---------|------|
| 网络效应 | 用户自增长+低获客成本 | Visa、微信 |
| 成本优势 | 同质产品但成本更低 | Costco、台积电 |
| 无形资产 | 品牌/专利/监管牌照 | 可口可乐、辉瑞 |
| 转换成本 | 用户换你的产品代价很高 | Salesforce、Oracle |
| 效率规模 | 市场只够养1-2家 | 铁路、公用事业 |

### 护城河宽度

| 评分 | 分类 | ROIC标准 |
|------|------|---------|
| 8-10 | 宽护城河（20年+优势）| ROIC 持续且显著 > WACC |
| 6-8 | 窄护城河（10-20年）| ROIC 适度 > WACC |
| 4-6 | 无护城河 | ROIC ≈ WACC |
| <4 | 护城河在恶化 | ROIC 向 WACC 收敛或低于 |

## 五、财报深读：8阶段SEC报告分析

当深度分析个股时，按以下8阶段解读财报（10-K/10-Q）：

1. **文件定位**：报告类型、时间段、审计师意见、重述历史
2. **MD&A深读**：收入驱动力、利润率趋势、流动性、前瞻性指引
3. **三表分析**：
   - 利润表：收入质量、非经常性项目、GAAP vs non-GAAP差异
   - 资产负债表：债务结构、商誉占比、表外义务
   - 现金流量表：经营/投资/融资三大类，FCF真实性
4. **风险因素**：新增/移除/升级的风险，诉讼，持续经营疑虑
5. **附注与会计**：关键估计、关联交易、分部变化
6. **管理层语气**：模糊语言（hedging）vs 具体承诺，可信度评估
7. **同比对比**：加速/减速/恶化趋势
8. **内部人活动**：高管买卖信号

### 会计质量评分（0-21分）

| 维度 | 分值 |
|------|------|
| 收入确认清晰度 | 0-3 |
| Non-GAAP调节合理性 | 0-3 |
| FCF转化率 | 0-3 |
| 运营资金变化 | 0-3 |
| 附注透明度 | 0-3 |
| 审计师意见 | 0-3 |
| 关联交易披露 | 0-3 |

| 总分 | 评价 |
|------|------|
| 18-21 | 优秀（高透明度）|
| 12-17 | 良好 |
| 6-11 | 需关注 |
| 0-5 | **红旗：红队必须重点攻击** |

## 六、红旗检测清单

分析个股时，以下红旗如果命中，红队攻击力度自动升级：

### 财务红旗
- 应收账款增速 > 收入增速（可能在塞渠道）
- 经营现金流持续 < 净利润（利润质量差）
- 频繁变更会计政策
- 审计师出具非标意见
- 关联交易金额大且披露模糊

### 运营红旗
- 核心管理层离职（CFO离职尤其危险）
- 客户集中度 > 30%（大客户流失=灾难）
- 毛利率持续下降但收入增长（可能在打折冲量）

### 治理红旗
- CEO/CFO大额减持（>持仓10%）
- 股权激励过度稀释
- 董事会缺乏独立性

### 估值红旗
- P/E > 行业均值 2倍以上（当前定价已包含完美执行预期）
- 市值/FCF > 50（需要很多年才能"赚回来"）
- 所有分析师一致看多（反向指标）

## 七、加权综合评分（Research Bundle模型）

对个股做完整分析后，使用以下5维度加权综合：

| 维度 | 权重 | 评分范围 | 评什么 |
|------|------|---------|--------|
| 业务质量 | 25% | 0-10 | Piotroski + 护城河 + 管理层 |
| 估值 | 25% | 0-10 | DCF安全边际 + 可比公司 |
| 市场信号 | 20% | 0-10 | 内部人交易 + 机构持仓 + 管理层语气 |
| 技术面 | 15% | 0-10 | 趋势 + 支撑阻力 + 动量 |
| 风险 | 15% | 0-10 | 红旗数量 + 下行空间 + 催化剂风险 |

**综合评分 = Σ(维度分 × 权重)**

| 综合分 | 信号 |
|--------|------|
| 8.0-10.0 | Strong Buy |
| 6.5-7.9 | Buy |
| 5.0-6.4 | Hold / Watchlist |
| 3.5-4.9 | Underweight |
| 0-3.4 | Sell / Avoid |

**原则**：业务质量和内在价值优先于短期价格行为。当基本面和技术面冲突时，基本面胜出——但必须记录冲突而不是掩盖。

## 八、统一信号输出格式

所有个股分析完成后，输出标准化信号块：

```
📊 个股分析信号
──────────────────────────
标的：[代码] ([公司名])
信号：BULLISH / NEUTRAL / BEARISH
置信度：HIGH / MEDIUM / LOW
时间范围：SHORT / MEDIUM / LONG-TERM
综合评分：X.X / 10
操作：BUY / HOLD / SELL
信念强度：STRONG / MODERATE / WEAK
──────────────────────────
关键理由（1-3句）：...
最大风险（1句）：...
下一步催化剂：[事件] [日期]
```

然后进入红蓝对抗流程（`agents/red-team-protocol.md`）。

## 九、商品类个股的特殊处理

CCJ（Cameco）、FCX（Freeport铜）等商品类个股需要**双重框架**：

1. **先走 commodity-analysis.md**：分析铀/铜的供需、周期位置、比率
2. **再走本框架（equity-analysis.md）**：分析公司本身的财务、估值、管理层
3. **综合判断**：商品方向 × 公司质量 = 最终信号
   - 商品看多 + 公司质量高 = 最强买入信号
   - 商品看多 + 公司质量差 = 可以用ETF（URA）替代个股
   - 商品看空 + 公司质量高 = 等待，不追
