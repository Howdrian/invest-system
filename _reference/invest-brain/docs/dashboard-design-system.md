# Dashboard v2 设计系统：机构浅色投研 Cockpit

> 适用范围：`dashboard.html`、`dashboard_portfolio.html`、`dashboard_opportunities.html`、`dashboard_evidence.html`、`dashboard_system.html`。  
> 目标：让用户打开首页 10 秒内知道今天该看什么；详情放子页，不把工程日志堆到首页。

## 1. Dashboard 用户目标

首页只回答 6 个问题：

1. 今天正式报告跑了吗；
2. 当前持仓安全吗；
3. 今天最该盯什么；
4. 是否触发审查；
5. 数据可信到什么程度；
6. 下一步该看哪里。

首页不是完整研究报告，不是交易下单界面，也不是 source health 日志页。

## 2. 信息架构原则

```text
首页 dashboard.html
  顶部状态条
  今日负责人结论
  持仓 Cockpit
  今日 Top 3 Watch
  门控 Stepper
  数据可信度摘要

持仓页 dashboard_portfolio.html
  账户权益 / 当前持仓 / P&L / 成本暴露 / 公告事件 / 板块联动 / 风险缺口

机会页 dashboard_opportunities.html
  市场结构 / 主题热度 / 新机会候选 / 历史 XLK-SMH-COPX / 等承接 / 缺证据

证据链页 dashboard_evidence.html
  CIO / 红蓝 / 评分状态 / 阻断归因 / 事实 → 推理 → 结论 / evidence pack

系统页 dashboard_system.html
  source health / source recovery / 自动化 / 补跑 / Dashboard 产品审核 / 截图审核
```

规则：持仓优先于新机会；当前信息优先于历史预审；投资内容和系统健康分层展示。

## 3. 首页 10 秒阅读规则

- 首页主区块最多 6 个；
- 总摘要不超过 420 字；
- 当前持仓必须以卡片出现，不用大表格；
- Top 3 每条固定为 `事实 / 为什么重要 / 触发条件 / 来源`；
- 数据可信度必须解释影响范围，不能只写 `degraded`；
- 红蓝、评分、仓位、用户确认必须以 Stepper 展示；
- 首页不展示历史非持仓标的的长 CIO / 红蓝材料。

## 4. 颜色 token

```css
--bg: #F5F7FB;
--panel: #FFFFFF;
--panel2: #F8FAFC;
--text: #111827;
--muted: #667085;
--accent: #0F2E5F;
--accent-2: #2563EB;
--good: #059669;
--warn: #D97706;
--bad: #DC2626;
--line: #D9E1EC;
```

语义：

- 绿色：正常、可用、已完成；
- 橙色：观察、需要审查、证据待补；
- 红色：阻断、关键源不可用、未门控执行风险；
- 蓝色：导航、当前流程、信息说明。

## 5. 字体 / 间距 / 卡片 / 表格 / 标签规范

- 字体：`system-ui / -apple-system / BlinkMacSystemFont`；
- 数字：`tabular-nums`；
- 标题：600-800 weight；
- 正文：14-15px；
- 辅助信息：12-13px；
- 卡片圆角：14-18px；
- 首页不放大表格；表格只在子页使用；
- 标签使用中文状态：`完成 / 当前 / 等待 / 阻断`、`可用 / 部分可用 / 不可用`。

## 6. 图表使用规则

- 首页只放小型趋势或 KPI，不放复杂图；
- 折线图只用于时间序列；
- 条形图用于排行；
- 矩阵用于 source health；
- Stepper 用于流程；
- 图表必须有来源和 as-of；缺数据时显示原因，不造数据。

## 7. 金融表达边界

允许：

- `用户已买入 160644 39手`；
- `本次是买入审查`；
- `红蓝结论建议不操作`；
- `评分通过后等待用户确认`。

禁止：

- `建议现在买入`；
- `可以加仓`；
- `立即下单`；
- `小底仓参与`。

Dashboard 可以展示历史动作和门控结果，不能绕过：红蓝 → 评分 → 仓位 → 用户确认。

## 8. 截图级审核标准

截图审核必须回答：

1. 首屏是否能看到当前持仓；
2. 用户 10 秒内是否知道今天该看什么；
3. 首页是否超过 6 个主区块；
4. 是否出现 raw enum / 英文工程字段 / 本机路径；
5. Top 3 是否有事实、重要性、触发条件、来源；
6. 数据源降级是否说明影响范围和下一步；
7. 视觉是否有足够留白、对齐、层级和一致颜色；
8. 是否出现未门控交易建议。

若有持仓但首屏没有持仓卡，不能 PASS。若页面出现 raw enum 或未门控执行话术，不能 PASS。
